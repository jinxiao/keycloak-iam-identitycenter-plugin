# AWS Identity Center Theme

This directory contains the source for the `aws-identitycenter` Keycloak admin
theme.

Development layout:

```text
themes/aws-identitycenter/admin
```

Production archive layout is generated by Maven:

```text
target/keycloak-aws-identitycenter-sync-<version>-themes.jar
```

The archive follows the Keycloak theme-provider format:

```text
META-INF/keycloak-themes.json
theme/aws-identitycenter/admin/...
```

For local theme development, copy `themes/aws-identitycenter` into
`$KEYCLOAK_HOME/themes/aws-identitycenter` and run Keycloak with theme caches
disabled:

```bash
bin/kc.sh start-dev \
  --spi-theme--static-max-age=-1 \
  --spi-theme--cache-themes=false \
  --spi-theme--cache-templates=false
```
